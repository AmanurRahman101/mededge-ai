# Demo script (2:45)

Record the screen with the app on localhost or the deployed URL. Do not show `.env` or an unredacted real report.

1. **0:00** Start screen. Read the footer line once: MedEdge AI is an administrative pipeline, not a diagnostic tool.
2. **0:08** Choose "I'm a patient." Open the fictional CBC sample. Point at the red header and say the name and phone stay hidden, and the language model has not seen the page yet.
3. **0:28** Confirm the overlay. If a model key is set, the trace names the model that read the page. If not, the banner says this is a recorded reading of a fictional sample.
4. **0:50** Show the values copied as printed, including platelets in lakh/cumm. Share. Show the six-character code.
5. **1:05** Go back. Choose "I'm a doctor." Paste the code. The same record opens.
6. **1:20** Dictate one administrative sentence, for example "Outpatient visit, fasting specimen at 8:30, route to nephrology." Stop. The note appears in English fields. Do not say a diagnosis.
7. **1:40** Open a second sample with "Inject a fault" checked. Show the trace reporting the injected fault, then the repair or the "assembled by fallback" label.
8. **2:05** Approve and export. Open the FHIR tab. Point at the pseudonym, the copied creatinine value, and the dose text `1+0+1`.
9. **2:25** End on the footer line.

## X cut (under 45 seconds)

Start screen, patient confirm overlay, share code, doctor approve. Caption: paper lab sheet to a checked FHIR bundle, with the name hidden first. Same disclaimer in the post text.

## What this file does not do

Recording, posting, and the Cerebral Valley submission need the author's accounts. They are not checked in.
